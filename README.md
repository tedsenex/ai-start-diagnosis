# AI 時代起步診斷

李煜的對話式 AI 焦慮緩解診斷。訪客先選身份，再一題一題作答，最後拿到診斷報告，並用 LINE 預約一對一諮詢。

- **想創業／做自媒體**：9 個構面、約 50 題。報告包含準備度等級、AI 焦慮指數、建議路徑、優勢、要補強的地方、90 天行動計畫。
- **企業主／企業主管**：5 個構面、約 22 題。報告包含 AI 導入階段、每個痛點對應的 AI 做法、注意事項、90 天導入路線。

## 怎麼開始

1. 解壓縮後，用瀏覽器打開 `index.html` 就能直接用。
2. 在這個資料夾裡開啟 Claude Code。它會先讀 `CLAUDE.md`，裡面有程式結構、計分規則、品牌文字規則，以及在手機上踩過的雷。
3. 改完之後執行 `node tests/walkthrough.mjs` 自動測試，再用手機在 Messenger 和 LINE 裡實測一次。

## 上線

整個網頁只有 `index.html` 一個檔，丟到任何靜態主機就能上線，例如 Vercel、Netlify、GitHub Pages。

原始的評估系統設計（八構面、題庫、評分錨點、紅旗、諮詢流程）在 `docs/創業準備度評估系統.md`。
